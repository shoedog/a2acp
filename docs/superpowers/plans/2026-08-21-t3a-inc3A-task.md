### Increment 3A — typed construction and Git-authority port

Replace the `BridgeError` prose returned by `ExactAbsenceCandidateV1::from_claim` and `from_bound` with `ClaimAuthorityUnavailableV1`. A private helper may wrap that type, but the report must use the existing public vocabulary unchanged.

Replace the admitted-record `.ok()`/`unwrap_or(Refused)` tail with an explicit match:

- A construction failure returns `CustodyExactAbsenceAssessmentV1::CannotConstructSubject(CannotConstructSubjectV1::ClaimAuthorityUnavailable(...))`.
- Only a successfully constructed candidate may reach `decide_unused_candidate` and become `Assessed`.
- An error from `observe_exact_absence` after construction remains `Assessed(Refused)`, because an assessment was attempted.

Move repository-authority Git observation behind this port:

```rust
pub trait ExactAbsenceProbeV1: Send + Sync {
    fn observe_repository_authority(
        &self,
        source: &str,
    ) -> Result<DirectoryIdentityV1, BridgeError>;

    fn observe_exact_absence(
        &self,
        candidate: &ExactAbsenceCandidateV1,
    ) -> Result<ExactAbsenceObservationV1, BridgeError>;
}
```

`HostGitWorktree::observe_repository_authority` owns the synchronous equivalent of:

```text
git -C <source> rev-parse --path-format=absolute --git-common-dir
```

It returns the verified identity of the absolute common directory. Spawn failure, nonzero status, invalid UTF-8, empty or non-absolute output, or inability to capture that directory’s identity is an unavailable observation. No candidate-construction code in `sweep.rs` may run Git. The unrelated removal/pruning commands in `sweep.rs` are outside this requirement and must not be moved or changed.

Update all four implementations of `ExactAbsenceProbeV1`: `HostGitWorktree`, `BothAbsentProbe`, `RecordingProbe`, and `checked_scan::tests::Probe`. Recording probes must count repository-authority calls separately from exact-absence calls.

The final construction precedence is:

1. Increment 2 placement guards, unchanged.
2. Increment 2 population admission, unchanged.
3. Outer `canonical_path` versus embedded `directory_identity.canonical_path`, in `Source`, `Root`, `Worktree`, `CommonDirectory` order.
4. Absolute-path checks in the same order.
5. Complete `dev`/`ino` for `Source`, `Root`, and `CommonDirectory`, in that order.
6. Stable retained sweep-root availability and equality with the claim root.
7. Live source and common-directory filesystem observation and comparison.
8. `observe_repository_authority`.
9. Proof that the repository-observed common directory is the recorded, live common directory.
10. Candidate construction and exact-absence observation.

Worktree identity is deliberately excluded from step 5. A degraded worktree and a complete identity captured before the target disappeared are both admissible.

Map the current string sites exactly as follows:

| Current site or message | Required object/reason |
| --- | --- |
| `claim source path and identity disagree` | `Source / PathMismatch` |
| `claim source common directory path and identity disagree` | `CommonDirectory / PathMismatch` |
| `claim worktree path and identity disagree` | `Worktree / PathMismatch` |
| `source path has no absolute identity` | `Source / NotAbsolute` |
| `source common directory path has no absolute identity` | `CommonDirectory / NotAbsolute` |
| `worktree path has no absolute identity` | `Worktree / NotAbsolute` |
| `source identity probe failed: ...` | `Source / ObservationUnavailable` |
| `source common directory identity probe failed: ...` | `CommonDirectory / ObservationUnavailable` |
| `source has no bound object identity` | `Source / IdentityIncomplete` |
| `source common directory has no bound object identity` | `CommonDirectory / IdentityIncomplete` |
| Combined `source or common directory has no bound object identity` in `from_bound` | Split deterministically: `Source / IdentityIncomplete` first, then `CommonDirectory / IdentityIncomplete` |
| Source half of `claim source or common directory identity changed` | `Source / IdentityChanged` |
| Common-directory half of that message | `CommonDirectory / IdentityChanged` |

| `source authority probe returned no absolute common directory` | `SourceCommonDirectoryBinding / ObservationUnavailable` |

| Legacy `source does not own the recorded common directory` | Internally `SourceCommonDirectoryBinding / OwnershipUnproven`; its public legacy projection remains `Refused` |

Do not infer `IdentityChanged` merely because an observation could not be completed. `ObservationUnavailable` is the fail-closed result for failed canonicalization, metadata/descriptor observation, Git execution, or unusable Git output. `IdentityChanged` requires two complete identities that disagree.
