2. BLOCKER (WRONG) — Section: Required proving environments / AC 5, 34, 37. Issue: The spec mandates real APFS and ext4 evidence but defines neither a fixture-root input nor filesystem/mount attestation. Tests using a default temporary directory could execute on tmpfs or overlayfs while being reported as ext4, producing falsely labeled mandatory evidence. Suggested resolution: Define how each fixture root is supplied, verify and record its filesystem type and mount identity before testing, and specify the birthtime observation artifact.
